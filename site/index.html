      What this shows, and what it does not

      It shows the method: code first, a model only where words decide, a drafter check on every edit, a keyword baseline to beat, guards in code, numbers from scripts.

      It does not show real accuracy, real drafters (the simulated one knows the true house), images or production scale. The data, notes and prices are synthetic, and the free model is weak.

      Next, with real data: shadow mode next to the drafters, then drafter approval, then auto-apply only where the ladder allows; every drafter correction becomes a test case. Three questions for your drafters: which plan mistakes cost the most, what tolerance you accept on walls and ceilings, and how you count an archway.
